Privacy Policy

Last updated: October 24, 2026

Macro Deck Lights is a personal, single-user project that runs only on its owner's own computer.

What it accesses

When the owner signs in, the app asks for permission to send text commands to the Google Assistant (scope: Google Assistant SDK) so it can turn the owner's own lights on, off, or change their color and brightness.

What it stores

The sign-in token is stored only on the owner's computer, encrypted with Windows account encryption. Nothing is uploaded to any server run by this project.

What it shares

This project does not collect, sell, share, or transfer any personal data. Commands go directly from the owner's computer to Google.

Deleting access

The owner can revoke access at any time at myaccount.google.com/permissions.
